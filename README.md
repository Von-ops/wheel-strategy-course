# Wheel Strategy Course

A study site for learning covered calls, cash-secured puts and the wheel: 6 modules, a 3-week timeline, quizzes, a calculator, paper-trade drills, free Option Alpha and tastylive links, and embedded videos.

- **Tablet or phone:** open it in Safari, tap Share, then Add to Home Screen.
- **Offline:** after one visit, pages and the calculator are cached. Videos need internet.
- **Local:** run `python3 -m http.server 8765` in this folder, or open `index.html` directly.

Progress and drill notes save in your browser only (localStorage). Educational material, not financial advice.
